FReader v54 integration changes to @silurus/ooxml 0.89.8

Upstream: https://github.com/yukiyokotani/office-open-xml-viewer
License: MIT. Original LICENSE and THIRD_PARTY_NOTICES.md are retained.

Changed file: pptx-Ci1Y9SS_.js
- Added getFReaderSlideMetadata(index), returning a read-only snapshot of the
  slide part name and element IDs/types/origins through the existing slide cache.
- Added an optional freaderHiddenShapeIds Set to main-mode renderSlide options.
  Before drawing, a temporary slide model omits matching slide-origin elements.
  The source model is not mutated. Master/layout elements with colliding numeric
  IDs are not removed. Text selection is built from the filtered render runs.
- Other rendering paths and the WebAssembly parsers remain unchanged.

As in v53, ESM filenames/references use .js instead of .mjs for Android MIME
handling, and the legacy companion import points at the bundled engine.
PROVENANCE.json records both the upstream and installed file hashes.
