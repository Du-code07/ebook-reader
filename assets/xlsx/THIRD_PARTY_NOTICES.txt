The viewer reuses Noto Sans KR and Noto Serif KR from ../hwp/fonts/ with their
SIL Open Font License notices. No Microsoft fonts are included. Installed
fonts are preferred; substitution can change text metrics and line breaks.

FReader modifications: .mjs filenames and references renamed to .js for
Android asset MIME handling; legacy companion imports point to the bundled
engine. FReader v87 patches renderer-CCA_bQB8.js to test merged-cell
continuation membership with the range interval index in ../merge_ranges.js,
instead of expanding every covered coordinate. Original merged ranges,
anchor cells and their formatting remain intact. The local Flutter bridge,
mobile sheet panning/pinch zoom and position restoration are in reader.js.
PROVENANCE.json records pinned package integrity and per-file checksums.

All code and fonts are packaged locally. useGoogleFonts is false. Document
links cannot navigate the viewer. Files and passwords are not uploaded.

Supported formats: XLSX, XLSM, and the experimental BIFF8 subset of XLS.
This is a read-only viewer, not an Excel calculation engine. It shows stored
formula results without recalculation and never runs macros, external data
connections or embedded programs. Legacy XLS variants outside the supported
subset report an error and require an XLSX conversion. XLSB is not supported.
Sheets are continuous grids, not paginated print-layout replicas. Microsoft
Excel layout fidelity is not guaranteed for every feature or installed font.
